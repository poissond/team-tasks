# 페르소나 정의

> **MVP 헌장** — 단일 테이블 · 기능 5개 이하 · 1일 안에 코드로 옮길 수 있는 분량

---

## 페르소나 표

| 역할 | 기술 수준 | 주요 시나리오 |
|------|-----------|--------------|
| **팀장 / 프로젝트 매니저**<br>이서준 (38세)<br>5인 개발팀 리드 | 비개발자에 가까움.<br>스프레드시트·슬랙은 익숙하나<br>CLI·코드 편집 경험 없음 | ① 월요일 아침 전체 일감 현황을 한 화면에서 파악하고 싶다<br>② 마감이 지난 일감을 즉시 확인해 담당자에게 알리고 싶다<br>③ 새 스프린트 시작 시 일감을 일괄 등록하고 팀원에게 배정하고 싶다 |
| **시니어 개발자**<br>박민지 (31세)<br>풀스택 3년차 | 개발자.<br>키보드 중심 워크플로우 선호.<br>도구 전환 비용에 민감 | ① 내 담당 일감만 필터링해 오늘 집중할 작업을 빠르게 파악하고 싶다<br>② 일감 상태를 드래그 한 번으로 바꾸고 싶다 (할 일 → 진행 중 → 완료)<br>③ 작업 중 발생한 이슈를 설명 필드에 빠르게 기록하고 싶다 |
| **주니어 / 인턴 개발자**<br>최하람 (25세)<br>입사 3개월차 | 개발 입문 수준.<br>UI 조작은 익숙하나<br>업무 프로세스 파악 중 | ① 본인에게 배정된 일감 목록과 마감일을 한눈에 보고 싶다<br>② 완료한 일감을 체크해 팀장에게 진행 상황을 보여주고 싶다<br>③ 일감의 우선순위를 보고 무엇을 먼저 해야 할지 판단하고 싶다 |

---

## MVP 범위 (5개 기능)

| # | 기능 | 근거 페르소나 |
|---|------|--------------|
| 1 | 일감 CRUD (제목·설명·마감일) | 전체 |
| 2 | 상태 변경 (할 일 → 진행 중 → 완료) | 박민지, 최하람 |
| 3 | 담당자 배정 | 이서준 |
| 4 | 우선순위 표시 (높음 / 중간 / 낮음) | 이서준, 최하람 |
| 5 | 담당자·상태 필터 | 박민지, 이서준 |

**범위 밖 (v2 이후):** 댓글, 파일 첨부, 알림, 권한 관리, 반복 일정
