# 요건 정의

> 근거 문서: `docs/personas.md` · `docs/user-stories.md`
> MVP 헌장 준수 — 기능 요건 5개 이하, Phase 2 제안 없음

---

## 기능 요건

| ID | 이름 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | 일감 CRUD | 일감을 생성·조회·수정·삭제한다. 필수 입력: 제목. 선택 입력: 설명·마감일. 저장은 브라우저 localStorage에 즉시 반영된다. | 필수 |
| F-02 | 상태 변경 | 각 일감은 **할 일 → 진행 중 → 완료** 세 상태 중 하나를 가진다. 목록 수정 다이얼로그 또는 칸반 보드 드래그&드롭으로 변경할 수 있다. | 필수 |
| F-03 | 담당자 배정 | 일감에 팀원 1명을 담당자로 지정하거나 미배정 상태로 둘 수 있다. 팀원 추가·삭제 시 해당 일감의 담당자 배정이 자동 해제된다. | 필수 |
| F-04 | 우선순위 표시 | 일감에 **높음·중간·낮음** 세 단계 우선순위를 지정한다. 목록과 칸반 카드에 색상 뱃지로 표시하며, 목록 뷰에서 우선순위 기준 정렬을 지원한다. | 필수 |
| F-05 | 담당자·상태 필터 | 일감 목록에서 담당자, 상태, 우선순위 세 조건을 독립적으로 필터링한다. 대시보드는 상태별 집계와 기한 초과 일감을 항상 노출한다. | 필수 |

## 비기능 요건

### 성능

| ID | 항목 | 기준 |
|----|------|------|
| NF-P1 | 초기 로드 | 페이지 첫 로드(LCP) **2 초 이내** (로컬 localhost 기준, 일감 100건 이하) |
| NF-P2 | 인터랙션 응답 | 일감 추가·수정·삭제·상태 변경 후 UI 반영 **100 ms 이내** (localStorage 쓰기 포함) |

### 보안

| ID | 항목 | 기준 |
|----|------|------|
| NF-S1 | 데이터 노출 범위 | 모든 데이터는 해당 브라우저의 localStorage에만 저장되며, 외부 서버로 전송되지 않는다 (네트워크 요청 0건, 정적 에셋 제외) |
| NF-S2 | XSS 방지 | 사용자 입력(제목·설명)은 React의 기본 이스케이프를 통해 렌더링하며, `dangerouslySetInnerHTML` 사용 금지 |

### 가용성

| ID | 항목 | 기준 |
|----|------|------|
| NF-A1 | 오프라인 동작 | 인터넷 연결 없이도 모든 CRUD 기능이 정상 동작한다 (데이터가 localStorage에 존재하는 한) |
| NF-A2 | 데이터 유지 | 브라우저 새로고침·탭 재오픈 후에도 일감·팀원 데이터가 손실 없이 복원된다 |

### 접근성

| ID | 항목 | 기준 |
|----|------|------|
| NF-AC1 | 키보드 탐색 | 일감 추가 다이얼로그·필터·테이블의 모든 인터랙티브 요소를 Tab / Enter / Esc 키만으로 조작 가능 |
| NF-AC2 | 색상 대비 | 상태·우선순위 뱃지의 텍스트 대비비 **WCAG AA 기준 4.5 : 1 이상** (색상만으로 정보를 전달하지 않고 텍스트 레이블 병기) |
